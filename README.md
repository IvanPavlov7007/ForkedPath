## About the game

Classical shoot-em-up gamplay inspired by games such as **Pocky & Rocky** and **Elfazar's Hat (Ufo 50)**. 

You play as a hungry swine raiding the kitchen fighting hoards of various foods, that lead to a suprisnig boss fight.

## How to play
You can play this game by visiting linked itch io page attached to this project.

### Controls

This game allows you to switch various control themes.
